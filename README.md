# Student Gradebook CLI

A Python command-line application for managing courses, credits, and GPA.
This project is part of Extra-A (60–70) of the Mini-Portfolio.

## Features
- Add / Update / Delete course
- View gradebook in table format
- Compute overall GPA
- Compute GPA by semester
- Persistent storage using gradebook.json
- Input validation

## How to run
1. Install Python 3.8+
2. Open terminal
3. Run:
   python3 main.py

## Files
- main.py — program entry
- gradebook.py — business logic
- storage.py — JSON load/save
- utils.py — input validation
- gradebook.json — auto created

## Sample Data
Add at least 3 courses to test GPA.
